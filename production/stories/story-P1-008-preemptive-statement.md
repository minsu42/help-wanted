# Story P1-008: 선제 진술 — 순순히 줄 것은 앉자마자 전부 준다

> **Phase**: P1 | **Status**: Ready | **Layer**: Domain | **Type**: Logic
> **GDD**: `design/gdd/intake-system.md` (v6.2) R3 · F2 · Edge Cases 「축퇴 의뢰」 ·
> Tuning Knobs 「선제 진술 깊이」 · **Q7**
> **ADR**: ADR-001 / ADR-004 (Accepted)
> **Created**: 2026-08-10

## Context

**이 스토리가 「묻기」를 잡일에서 진단으로 바꾼다.**

의뢰인은 착석 즉시 칸마다 `min(knows, tells)` 단계까지 **스스로 진술한다.**
비용 없음. 그 결과가 이 시스템의 핵심 성질이다:

> **남은 빈칸은 전부 진짜 장애물이다** — 무지 아니면 은폐. 순순히 줄 답은 이미
> 화면에 있다.

이것이 없으면 플레이어의 첫 행동 여러 번이 *"의뢰인이 어차피 말해 줄 것을 굳이
클릭해서 받아내는 일"* 이 된다. 프로토 4 2회차의 판정이 정확히 그것이었다 —
***"순순히 말해 줄 것을 묻느라 수를 쓰는 것은 잡일이다."*** 같은 프로토가 묻기의
비용도 함께 없앴는데(R4), **두 조치는 한 몸이다**: 진단이 무료여야 진단을 하고,
진단할 것이 진짜 벽이어야 진단이 의미가 있다.

**그리고 깊이는 노브다 — 값이 셋이고, Q7이 열려 있다.**

| 값 | 뜻 | 역할 |
| ---- | ---- | ---- |
| **`전부`** (기본) | `min(knows, tells)`까지 전부 | 확정 설계 |
| `1단만` | `어렴풋`까지만 | **실험군** — 대화 리듬을 늘린다 |
| `최소` | `종류`만 | **대조군** — 잡일이 부활하는 기준점 |

**이 스토리는 Q7의 실험 장치를 소유한다.** 세 값을 고정 시드 위에서 결정론적으로
돌려 지표를 뽑는 하네스를 만든다 — 사람이 **말싸움이 아니라 플레이로** Q7에
답할 수 있게. 평가 질문은 GDD가 이미 써 두었다:

> ***추가 질문이 "대화"였나, 이미 줄 답을 다시 요구하는 "잡일"이었나?***

## Acceptance Criteria

### 선제 진술

- [ ] 착석 직후 칸마다 `min(knows[칸], tells[칸])` 단계까지 자동으로 채워진다.
      **인내는 초기값 그대로이고, 어떤 비용도 발생하지 않는다** — **AC-R3-01**
- [ ] 선제 진술 후 **남은 빈칸은 전부 `막힘` 후보다** — 즉, 그 칸을 물으면 반드시
      `모른다` 또는 `얼버무린다`가 나온다. **`말한다`가 나오는 빈칸이 존재하지
      않는다** — R3의 핵심 성질 *(전 직업 × 전 시드 몬테카를로로 확인)*
- [ ] `종류` 클램프가 선제 진술 **이전에** 적용된다. 갱단도 첫 진술에서 의뢰 종류를
      말한다 — F1 · **AC-F1-02**
- [ ] 갱단(`tells` 최저)의 선제 진술이 **다른 직업보다 유의미하게 짧다.**
      *"짧다는 것 자체가 정보"* 이므로, 길이가 직업과 무관해지면 실패다 — R3
- [ ] 선제 진술은 `knows`/`tells` **실현값을 바꾸지 않는다.** 상태를 드러낼 뿐
      생성하지 않는다 (F1이 유일한 RNG 지점) — R10

### 깊이 노브

- [ ] `balance.json`의 `intake.openingStatementDepth`가 **`전부` / `1단만` / `최소`**
      셋을 받는다. 기본 `전부`. **코드에 문자열이 박혀 있지 않다** *(정적)*
- [ ] `1단만`: `min(knows, tells, vague)`까지만 진술한다. `확실`까지 줄 수 있는 칸도
      `어렴풋`에서 멈춘다
- [ ] `최소`: `종류`만 진술한다. 나머지 칸은 전부 `미상`으로 남는다
- [ ] 셋 중 어느 값이든 **인내를 쓰지 않고, `knows`/`tells` 실현이 동일하다.**
      노브는 **드러내는 양**만 바꾼다 *(같은 시드 3회 실행 비교)*
- [ ] 세 값 모두에서 **모든 칸을 끝까지 채우는 경로가 존재한다** — `최소`가 막다른
      길을 만들지 않는다 (기둥 5)

### 축퇴 의뢰

- [ ] 전 칸 `none` 실현 시 **표면 진술이 반드시 나온다** (침묵하지 않는다) —
      **AC-EDGE-04**
- [ ] 그 상태에서 첫 물음이 **`모른다`로 응답**하고, 계약 진행이 가능하다 —
      **AC-EDGE-04**
- [ ] 축퇴는 **유효한 상태로 표시**되며 오류·경고·예외를 내지 않는다. 깨진 데이터와
      구별 가능하다 (표면 진술의 존재가 그 구별이다)
- [ ] `종류` 클램프 때문에 **완전한 축퇴(종류까지 `none`)는 발생하지 않는다** —
      경계 확인

### **Q7 실험 하네스**

- [ ] 고정 시드 집합(예: 50개) × 깊이 3값 × 직업 5종을 **결정론적으로** 돌리는
      실행 경로가 있다. 브라우저 없이 동작한다 (도메인 순수 함수만 쓴다)
- [ ] 실행마다 지표를 낸다: **선제 진술로 채워진 칸 비율** · **남은 빈칸 중
      `말한다`가 나오는 비율(목표 0%)** · 칸당 평균 묻기 횟수 · 최종 완성률
- [ ] **잡일 지표를 명시적으로 센다**: *"이미 줄 답을 다시 요구한 묻기"* = 물었더니
      `말한다`가 나온 횟수. **`전부`에서 이 값이 0이고, `최소`에서 커지는 것이
      대조군의 존재 이유다**
- [ ] 같은 시드 집합으로 두 번 돌리면 **바이트 단위로 같은 보고서**가 나온다 —
      결정론
- [ ] 결과를 사람이 읽을 표 하나로 낸다 (`production/qa/evidence/`). **보고서가
      Q7에 답하지 않는다 — 사람이 답한다.** 하네스는 근거를 대는 것까지다

> **왜 하네스가 이 스토리의 것인가**: Q7은 *"사람이 만져야 안다"* 로 분류되어 있고
> 프로토 4회차가 담당이다. 그런데 **세 값을 손으로 갈아 끼우며 재현 가능하게 비교할
> 방법이 없으면 프로토는 인상 비평으로 끝난다.** 선제 진술을 만드는 사람이 노브도
> 만들므로, 노브를 세 방향으로 돌리는 장치까지가 한 덩어리다.

## Implementation Notes

- 파일: `src/domain/intake.ts` (P1-005와 같은 모듈). 하네스는
  `tools/intake-depth-experiment.ts`(가칭) — **`src/`가 아니다.** 게임 번들에 들어가지
  않는다 (런타임 의존성 0개 원칙 · 초기 로드 예산).
- **선제 진술은 상태 전이가 아니라 상태 드러내기다.** `knows`/`tells`는 F1이 이미
  실현해 두었고, 선제 진술은 그중 `min(knows, tells)`까지를 `slotState`로 **투영**할
  뿐이다. 새 RNG를 뽑지 않는다 — 뽑으면 AC-DET-01이 깨진다.
- **`min(knows, tells)`의 의미를 오해하기 쉽다.** `knows=확실, tells=어렴풋`이면
  선제 진술은 `어렴풋`까지다. 그 칸을 `확실`로 물으면 **`얼버무린다`** 가 나온다
  (F2: `tells < L`). `knows=어렴풋, tells=확실`이면 반대로 **`모른다`** 다.
  **두 경우가 다른 벽이고 다른 열쇠를 요구한다** — 그것이 P1-005가 여는 문이다.
- **깊이 노브를 진술 생성 쪽에만 걸어라.** 판정(F2)에 걸면 `최소`에서 물었을 때
  `말한다`가 안 나오게 되고, 그러면 대조군이 측정하려던 잡일이 사라져 실험이 무의미해진다.
  **`최소`에서 묻기가 잡일이 되는 것이 정확히 관찰 대상이다.**
- **갱단의 짧은 진술은 코드가 아니라 데이터가 만든다.** `tellsDist` `[70,25,5]`가
  자동으로 짧게 만든다. 직업별로 진술 길이를 따로 손대지 마라 — 손대는 순간
  *"짧다는 것 자체가 정보"* 가 연출이 되고, 플레이어가 배울 수 있는 규칙이 아니게 된다.
- **축퇴 의뢰는 방어 코드로 잡지 마라.** 확률 `0.3%`이고 GDD가 **유효한 상태**라고
  못박았다. `if (allNone) throw` 나 재추첨은 오구현이다 — 재추첨은 결정론을 깬다.
  요구는 하나다: **표면 진술이 나온다.**
- 대사 문자열은 LLM 생성이고 판정 밖이다 (R11). **하네스는 대사를 부르지 않는다** —
  게이트웨이 없이 돌아야 한다.
