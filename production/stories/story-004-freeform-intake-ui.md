# Story 004 — 한 문장 자유 심문 UI

## Goal

질문·주장·자료 근거·협상 금액을 모두 한 문장으로 입력하는 창구 화면을 구현한다.

## Scope

- 1~240자 자유 입력창과 전송
- 독립된 자료집 열람 패널
- 대화 기록과 의뢰인 표정
- AI 대기·오류·재시도
- 한글 IME와 부분 갱신
- 개발 모드의 구조화 해석 검사 패널

## Acceptance Criteria

- 대화 입력 영역에는 문장 입력창과 전송 버튼만 있다.
- 질문 유형·태도·화법·근거를 별도로 선택하는 컨트롤이 없다.
- 자료집은 읽고 검색할 수 있지만 대화창으로 드래그하거나 연결할 수 없다.
- 문장 속 자료 인용은 AI가 지식 ID로 해석하며 서버가 가시성과 관련성을 검증한다.
- AI 응답 중 입력값, 포커스, 캐럿과 한글 조합 상태가 보존된다.
- 응답 2초 전후로 의뢰인의 대기 행동이 시작된다.
- 오류 재시도 시 원래 문장이 보존된다.
- 키보드만으로 입력, 전송과 자료집 열람이 가능하다.
