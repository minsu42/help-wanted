# Story 003 — AI 의뢰인 에이전트 Worker

## Goal

자유 발화를 구조화하고 규칙 도구를 호출한 뒤 허용 결과만 인물 대사로 생성한다.

## Scope

- `InterpretedTurn` 스키마
- 5개 허용 도구
- 시스템 프롬프트와 페르소나
- 도구 영수증 기반 최종 대사
- 이중 출력 검증
- 호출 제한, 헬스체크, 오류 재시도

## Acceptance Criteria

- 미공개 사실 원문이 모델 요청에 포함되지 않는다.
- 허용되지 않은 도구와 ID는 실행되지 않는다.
- 도구 결과와 반대되는 대사는 플레이어에게 표시되지 않는다.
- AI 문장만으로 상태가 변하지 않는다.
- 같은 `turnId` 재전송은 같은 영수증을 반환한다.
- 연속 호출 실패 시 입력과 기존 상태가 보존된다.
- API 키는 Worker 시크릿 외 위치에 존재하지 않는다.
