# Story 008 — 통합·배포·NAN 제출

## Goal

처음부터 결산까지 안정적으로 완주하는 예선 빌드와 제출물을 만든다.

## Scope

- 전체 상태 흐름
- Worker 프로덕션 연결
- GitHub Pages 배포
- 1280×720 브라우저 스모크
- 시연 영상
- 게임 소개서와 AI 기술 문서

## Acceptance Criteria

- 심사자가 별도 키 입력 없이 배포 URL에서 시작할 수 있다.
- 의뢰인 3명과 결산을 15분 안에 완주한다.
- 자유 발화 → AI 도구 → 의뢰서 → 결과 인과가 시연 영상에 나타난다.
- 프롬프트 인젝션 테스트에서 미공개 사실이 누출되지 않는다.
- AI 오류 후 재시도로 같은 입력을 복구할 수 있다.
- `npm run check`가 통과한다.
- gzip 초기 전송 총량이 1MB 이하이다.
