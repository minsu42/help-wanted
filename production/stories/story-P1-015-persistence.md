# Story P1-015: 지속성 — ADR-002를 코드로 옮긴다

> **Phase**: P1 | **Status**: Ready | **Layer**: Domain | **Type**: Logic
> **GDD**: `design/gdd/intake-system.md` (v6.2) Edge Cases 「결정론」 · AC-DET-01~04
> **ADR**: ADR-002 D1~D9 · ADR-003 D5
> **Created**: 2026-08-10

## Context

**ADR-002는 Accepted이고 한 줄도 구현되지 않았다.** `src/domain/save.ts`가 없고
`Rng.snapshot()`이 없다. 즉 **지금 이 게임은 원리적으로 저장이 불가능하다** —
`createRng`의 `state`가 클로저에 갇혀 있어 현재 상태를 읽을 방법이 없기 때문이다.

캠페인이 8~15시간이고 세션이 30~60분이다. **한 탭에서 8시간을 하는 사람은 없으므로
지속성은 선택이 아니다.**

그리고 **지금이 마이그레이션 비용이 정확히 0인 유일한 시점이다** — 세상에 세이브
파일이 0개다. ADR-002가 스스로 그렇게 적었고, 그 문장은 **아직 유효하다.**

  (…) **도메인 타입에 필드를 하나 추가하면 저장 포맷이 조용히 바뀐다.**"* /
  *"명시적 DTO는 도메인 타입이 바뀌면 **매핑 함수가 컴파일 에러를 낸다.**"*
- **D4** — *"`GameConfig`(= `balance.json`)와 `names.json`은 **세이브에 들어가지
  않는다.**"* — 대가: 밸런스 패치가 기존 세이브에 소급 적용된다.
- **D5** — *"하루가 끝날 때(`advanceDay` 직후) 한 번 쓴다. 그 외 저장 지점은
  **없다**. 슬롯 하나를 덮어쓴다. (…) 키: `helpWanted.save.v1` (**스키마 버전을
  키에 넣어** v2와 공존 가능하게 한다)"*

  *"하루 마감 세이브를 다시 불러 같은 결정을 하면 **결과가 바이트 단위로 같다.**"*
- **D7** — *"모르는 `schemaVersion` → **불러오지 않는다. 파일을 지우지도 않는다.**"*
  / *"**부분 복원을 시도하지 않는다.**"* / *"저장 실패 → **게임은 계속된다.**"*

  청취록·대화 이력·인내는 **계약 단위 휘발**.
- **D9 ⚠ 절** — *"**실제 위험 `T`는 세이브에 평문으로 두지 않는다** — 템플릿 id +
  시드로 재구성한다."* / *"`T`가 세이브에 평문으로 있으면 그 긴장이 **텍스트 에디터

## Acceptance Criteria

- [x] `Rng`에 `snapshot(): number`가 추가된다. 구현은 `snapshot: () => state` 한 줄.
      **`restoreRng` 같은 새 팩토리를 만들지 않는다** — 복원은 `createRng(saved.rngState)`
      (D1)
- [x] *(정적)* `snapshot()`을 **게임 로직이 읽지 않는다** — 호출자가 `save.ts`와
      테스트뿐이다 (D1)
- [x] **RNG 이어짐**: `createRng(rng.snapshot())`과 원본이 각각 100회 뽑아 **같은
      수열**을 낸다 (D1)
- [ ] `src/domain/save.ts`에 **명시적 DTO**가 있다 — `SaveFileV1`·`GameStateDtoV1`·
      `toSave`·`fromSave`. **`JSON.stringify(gameState)` 경로가 존재하지 않는다** (D3)
- [ ] *(정적)* 도메인 타입에 필드를 추가하면 **매핑 함수가 컴파일 에러를 낸다** —
      DTO가 `Partial`/인덱스 시그니처/`any`로 새지 않는다 (D3)
- [ ] `Map`/`Set`이 DTO에서 배열로 펴지고 **정확히 복원된다** (D3)
- [ ] `SAVE_SCHEMA_VERSION` 필드가 파일 안에 있고, **스토리지 키에도 버전이 있다** —
      `helpWanted.save.v1` (D5)
- [ ] 저장 시점이 **하루 마감뿐**이다 — `advanceDay` 직후 1회. *(정적)* 그 외
      저장 호출 지점 **0개**. 슬롯 **하나**, **자동**, 수동 저장·이름 붙인 슬롯·
      분기 저장 없음 (D5)
- [ ] **설정은 저장되지 않는다** — `SaveFileV1`에 `balance.json`/`names.json` 값이
      없고 `fromSave(file, config)`가 현재 설정을 주입받는다 (D4)
- [ ] 모르는 `schemaVersion` / JSON 파싱 실패 / 필수 필드 누락 → **불러오지 않고,
      파일을 지우지도 않고, 크래시 없이 새 회차로 시작하며 한 번 알린다.**
      **부분 복원 경로가 존재하지 않는다** *(정적 + 단위)* (D7)
- [ ] 저장 실패(용량 초과·시크릿 모드) → **게임이 계속된다.** 조용히 삼키지 않고
      한 번 알린다 (D7)
- [ ] *(정적)* `src/domain/**`에 `localStorage`가 **0건**이다. I/O는 프레젠테이션
      어댑터가 소유한다 (D8)
- [ ] **왕복 항등** — `fromSave(toSave(s), config)`가 원본과 같은 상태를 만든다
- [ ] **AC-DET-04** — `('unknown',—)`/`('blocked','knowledge')`/`('blocked','disclosure')`/
      `('vague',—)`/`('certain',—)` **5종이 왕복에서 구별 보존**된다. 하나라도
      뭉개지면 실패
- [ ] **AC-DET-02** *(정적)* — `SaveFileV1` 타입에 **대화 이력·연기 대사 필드가
      없다.** 청취록·인내도 없다 (D9)
- [ ] **AC-DET-03** — 게이트웨이 목을 **서로 다른 두 응답 집합**으로 바꿔 같은
      `(칸, 행동, 재료?)` 시퀀스를 재생하면 **세이브 바이트가 동일**하다.
      D9의 핵심 주장을 증명하는 유일한 테스트다
- [ ] *(정적 + 값)* **`T`(실제 위협)가 세이브 파일 텍스트에 평문으로 나타나지
      않는다.** 파견 전에 `localStorage`를 열어 정답을 읽을 수 없어야 한다.
      **그리고 복원 후에는 원본과 같은 `T`를 가진다** — **두 조건을 한 테스트에서
      같이 본다** (없애기만 하면 통과하는 테스트가 되지 않도록) (D9 ⚠ 절 · AC-CF-08)
- [ ] **위험도 등급(플레이어 판정)과 주장 등급이 서로 다른 값일 때 둘 다 구별되어
      복원된다** — 한 필드로 뭉갠 구현은 왕복 항등을 통과하면서도 P2를 죽인다 (D9)
- [ ] **되감기 무의미** — 하루 마감 저장 → 하루 진행 → 복원 → 같은 결정으로 하루
      진행, **두 결과가 동일**. 세이브 스캐밍을 **막지는 않는다** (D6)

## Implementation Notes

- 파일: `src/domain/rng.ts`(확장) · `src/domain/save.ts`(신설, 순수) ·
  프레젠테이션 쪽 `localStorage` 어댑터(신설)
- **DTO 매핑을 손으로 쓴다.** `GameState`가 12필드 + 중첩이라 초기 작성량이 있다 —
  **그것이 이 결정이 사는 값이다.** 자동화하면 D3의 이유가 사라진다
- **`T` 재구성은 `fromSave`가 `config`를 주입받는 D4 구조 위에 선다** — 템플릿 id와
  시드를 저장하고 거기서 다시 뽑는다. ⚠ 대가: `quest-templates.json`의 `T`를
  밸런싱으로 바꾸면 **진행 중인 세이브의 실제 위험이 바뀐다.** D4가 이미 받아들인
  것과 같은 성격이므로 같은 근거로 감수한다
- **완벽한 방어인 척하지 않는다** — 템플릿 id가 세이브에 있고 `quest-templates.json`은
  공개 번들이므로 작정하면 알아낼 수 있다. 닫는 것은 **우연히 보이는 경로**뿐이다
- ⚠ **`Rng`를 목으로 만드는 테스트가 있으면 `snapshot`을 추가해야 한다** (인터페이스
  변경, ADR-002 「대가와 위험」 1번)
- ⚠ **하루를 중간에 끊으면 그날이 통째로 날아간다.** 숨기지 않는다 — 중간 저장을
  넣는 순간 D6이 무너진다. **D9와 D6은 한 몸이다**
- 세이브 크기는 문제가 아니다 — 수십 KB 수준이고 `localStorage`는 통상 5MB.
  **초기 로드 예산과 무관하다**

## Out of Scope

- 하루 중간 저장 — **도입하려면 D5·D6·D9를 함께 여는 새 ADR이 필요하다**
- 여러 슬롯·수동 저장·분기 저장 — D6이 명시적으로 기각했다
- `Client` 저장소 분리(과거 의뢰인 조회) — **P6**. 추측으로 필드를 넣지 않는다
- 세이브 파일 내보내기/가져오기 UI
- LLM 배선 — P1-013 / 프록시 배포 — P1-014
