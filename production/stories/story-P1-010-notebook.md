# Story P1-010: 수첩 — 접히되 잠기지 않는다

> **Phase**: P1 | **Status**: Ready | **Layer**: Presentation | **Type**: UI

## Context

**수첩은 이 게임의 유일한 열쇠 꾸러미다.** `막힘(무지)` 칸은 `일깨우기`로만
열리고, `막힘(은폐)` 칸은 `들이대기`로만 열리며, 둘 다 **재료가 수첩에서
나온다.** 수첩이 없으면 P1의 막힌 칸은 **하나도 안 열린다** — 그래서 청취 GDD의
Dependencies에서 길드마스터북(#26)이 Soft에서 **Hard로 올라왔다.**

묶음은 셋이고 **쓰임이 다르다**:

| 묶음 | 내용 | 쓰임 | P1 |
| ---- | ---- | ---- | ---- |
| **들은 것** | 이 대화에서 얻은 사실 | **들이대기만** | ✅ |
| **길드마스터북** | 도감·시세·지역·조직 | 일깨우기 · 들이대기 | ✅ |
| **소문** | 밖에서 사 온 사실 | 일깨우기 · 들이대기 | ⬜ **P4 — 범위 밖** |

**「들은 것」이 일깨우기에 못 쓰이는 것은 버그가 아니라 축의 정의다.**
일깨우기는 *"내가 밖에서 가져온 것을 준다"* 이므로, 이 대화에서 방금 들은 것을
되돌려주는 것은 일깨움이 아니다. 이 규칙이 없으면 *"캐물으면 다 나온다"* 가 되고
**무지 축이 통째로 죽는다** (R5).

### 이 스토리가 지키는 단 하나의 금지

> **유효한 재료를 미리 알려주지 않는다.**
> `hintTags`·`leverageTag`로 **정렬·색칠·비활성 처리 금지.**
> **무엇이 통할지 아는 것이 곧 퍼즐이다.**

그리고 그 금지의 쌍둥이:

> **책은 접히되 잠기지 않는다.**
> 막혀야만 열리는 규칙 · 막힌 순간의 자동 펼침 · 관련 탭 강조 **전부 금지.**

**이 두 금지가 v5로의 퇴행을 막는 유일한 방어선이다.** v5는 *"재밌다"* 판정을
받고도 ***"선택지 고르기 게임"*** 이라는 판정으로 죽었다. 책이 막힌 순간 알아서
펼쳐지고 맞는 탭이 강조되면, 남는 조작은 **강조된 것을 고르는 일**뿐이다 —
그것이 정확히 v5다. 목표 경험은 *"막혔으니 후보를 고른다"* 가 아니라
**"아까 읽은 것이 이 상황에 걸린다"** 다.

## Acceptance Criteria

- [ ] 수첩이 **묶음 2종**(`들은 것` · `길드마스터북`)으로 갈려 표시된다. 소문 묶음은 P1에 **존재하지 않는다** (U3)
- [ ] `[일깨운다]`를 고르면 목록에 **길드마스터북 항목만** 나온다 — 「들은 것」이 **한 건도 나타나지 않는다** — **AC-R5-02** *(정적)* (R5)
- [ ] `[들이댄다]`를 고르면 **두 묶음 모두** 재료가 된다 (R6)
- [ ] *(정적)* 수첩이 `hintTags`·`leverageTag`로 **정렬하지 않는다** — 렌더 경로에 그 필드를 읽는 비교 함수·`sort` 호출이 0개다 — **AC-UI-05**
- [ ] *(정적)* 수첩이 `hintTags`·`leverageTag`로 **색칠하지 않는다** — 그 필드가 CSS 클래스·인라인 스타일·`data-*` 속성으로 DOM에 도달하지 않는다 — **AC-UI-05**
- [ ] *(정적)* 수첩이 `hintTags`·`leverageTag`로 **비활성 처리하지 않는다** — 목록에 `disabled`·`aria-disabled`가 0개다. **틀린 재료도 똑같이 고를 수 있다** (U3 · 아트 §5.4)
- [ ] 목록 순서가 **입력 순서 그대로**다 — 같은 수첩 상태면 같은 순서이고, 칸이나 의뢰인에 따라 순서가 바뀌지 않는다 (U3)
- [ ] **물러나기 비용 0** — 수첩을 열었다 닫는 것이 인내·상태·턴에 아무 영향이 없다. 몇 번이든 가능하다 (U3)
- [ ] *(정적 + 실브라우저)* **막혀야만 열리는 규칙이 없다** — 청취 어느 시점에서도 수첩을 열 수 있고, 칸 상태를 조건으로 여는 코드 경로가 0개다 (U3)
- [ ] *(정적 + 실브라우저)* **막힌 순간의 자동 펼침이 없다** — 칸이 `막힘`이 되어도 수첩이 스스로 열리지 않는다. 상태 전이가 수첩의 열림/닫힘을 건드리는 경로가 0개다 (U3)
- [ ] *(정적 + 실브라우저)* **관련 탭 강조가 없다** — 현재 막힌 칸에 따라 묶음·항목의 시각 표현이 바뀌지 않는다. 같은 수첩이 어느 칸에서 열어도 **똑같이 보인다** (U3)
- [ ] *(정적)* 후보 0개일 때 **목록 자체를 그리지 않는다** — 빈 상자·「해당 없음」 문구를 띄우지 않는다 (아트 §5.4)
- [ ] *(정적)* 재료가 하나도 없으면 `[일깨운다]`가 애초에 **뜨지 않는다** — **AC-R9-01** (R9 · P1-009와 짝)
- [ ] 재료 목록이 **떠 있는 상자로 보이지 않는다** — `box-shadow: none`, `border: none`, 종이와 같은 질감·잉크, 절취선 점선 경계, 잉크 화살표 `▸` (아트 §5.4)
- [ ] *(정적)* 목록에 아이콘 폰트·SVG 아이콘·검색창·필터 컨트롤이 0개다 (아트 §5.4)
- [ ] 길드마스터북 내지가 **평문**이다 — 체크박스·체크 표시·정답 표기가 0개다 (아트 §5.6)
- [ ] 「들은 것」이 이 대화에서 얻은 사실을 **모두** 담아 과거 진술 열람을 맡는다 (U1)
- [ ] 키보드 단독으로 수첩 열기 → 묶음 이동 → 재료 선택 → 물러나기가 완주된다 (U5)
- [ ] 수첩 열기/닫기가 100ms 이내로 반영된다

> **실브라우저 검증은 권장이 아니라 완료 기준이다.** 위 「자동 펼침 없음」·「탭 강조
> 없음」은 **정적 검사만으로는 절반만 잡힌다** — 코드에 조건 분기가 없어도 CSS
> `:has()`나 부모 클래스 전파로 같은 효과가 우연히 생길 수 있다. 이 저장소는
> 407개 통과 상태에서 SVG 클릭이 무시된 전례가 있다.

## Implementation Notes

- 파일: `src/presentation/ui/Notebook.ts` (신설) — P1-009의 `IntakeScreen`에
  **부분 모듈로 마운트된다.** 별도 화면이 아니다
- 화면 모듈 규약 준수: 리스너는 `IntakeScreen` 루트 하나에 위임되고, 수첩은
  `data-action="pick-material"` + `data-material-id`만 낸다
- ⚠ **`target instanceof HTMLElement` 금지.** 잉크 화살표를 SVG로 그리면 클릭이
  조용히 죽는다 — 이 저장소가 실제로 낸 버그다. `closest()`를 `Element`에서 출발
- **`hintTags`/`leverageTag`를 렌더 함수의 인자로 아예 넘기지 않는 것이 가장 싼
  방어다.** 넘겨 놓고 "쓰지 않는다"고 약속하면 다음 사람이 정렬을 넣는다. 렌더가
  받는 것은 `{ id, bundle, text }` 셋이면 충분하고, **태그는 판정 함수만 본다**
- **일깨우기/들이대기의 재료 필터링은 도메인이 한다.** 화면은 받은 목록을 그대로
  그린다 — 「들은 것 제외」를 화면에서 구현하면 도메인 테스트가 그것을 못 잡는다
- 접힘/펼침은 **표현이다.** 상태를 `notebookOpen: boolean` 하나로 두고, **그것을
  쓰는 곳이 사용자 조작 핸들러 하나뿐**이도록 유지한다. 판정 코드가 이 값을
  건드리면 위 금지가 무너진다
- 책 문안은 **개념·통념·소문 층위**로 쓴다. *"트롤은 햇빛에 약하다"* 가 아니라
  *"오래된 광부들은 낮에 무너진 갱을 들여다보길 꺼리지 않았다고 한다"* 쪽이다 —
  **추론 거리가 "아!"의 크기다.** 실제 문안은 #26 소관

## QA Test Cases

- **Manual: 「들은 것」이 일깨우기에 안 나오는가**
  - Setup: 청취로 칸 두 개를 채운 뒤, `막힘(무지)` 칸에서 `[일깨운다]`
  - Verify: 방금 얻은 사실이 목록에 **없다**. 길드마스터북 항목만 있다
  - Pass: 같은 상태에서 `[들이댄다]`를 고르면 그 사실이 **나타난다**
- **Manual: 정답을 알려주지 않는가**
  - Setup: `막힘(은폐)` 칸에서 `[들이댄다]` → 수첩
  - Verify: 어떤 항목도 강조·비활성·상단 고정되어 있지 않다. 순서가 항상 같다
  - Pass: 목록만 보고는 **무엇이 통할지 알 수 없다**
- **Manual: 책이 잠기지 않는가 / 스스로 열리지 않는가**
  - Setup: 청취 시작 직후(막힌 칸 0개) 수첩을 연다 → 닫는다 → 칸을 물어 `막힘`을 만든다
  - Verify: ① 막힌 칸이 없어도 열린다 ② 칸이 막히는 순간 **저절로 열리지 않는다** ③ 열었을 때 특정 묶음이 미리 선택되어 있지 않다
  - Pass: 세 조건 모두 만족
- **Manual: 물러나기가 공짜인가**
  - Setup: 수첩을 열고 닫기를 10회 반복
  - Verify: 인내 눈금·칸 상태·대사 흐름이 전부 그대로다
  - Pass: 아무 대가가 없다
- **Manual: 떠 있는 상자로 보이지 않는가**
  - Verify: 재료 목록에 그림자·둥근 모서리·흰 배경·테두리가 없다
  - Pass: 종이의 연장으로 읽힌다 — 드롭다운으로 보이면 실패 (아트 §5.4 조건부 통과)
- **Manual: 후보 0개**
  - Setup: 재료를 하나도 갖지 않은 상태로 `막힘(무지)` 칸에 도달
  - Verify: `[일깨운다]`가 뜨지 않고, 빈 목록 상자도 뜨지 않는다
  - Pass: 막다른 길처럼 보이지 않는다 — `[넘어간다]`가 그대로 있다
