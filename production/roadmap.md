# NAN 2026 예선 제작 로드맵

> **기준 콘셉트:** AI 의뢰인 × 진술·백과사전 대조 × 게시 의뢰 지원 판정
>
> **목표:** 서로 다른 진실성 유형의 의뢰인 6명과 첫 3사건 15분 시연 경로
>
> 기존 길드 경영 구현은 재사용 가능 여부를 파일 단위로 판단하며, 새 범위의 완료로 간주하지 않는다.

## Ship Gate

예선 빌드는 다음 흐름을 실제 클릭과 타이핑으로 완주해야 한다.

```text
의뢰인 1 착석
  → 자유 질문
  → 진술 쪽지와 백과사전 문장 대조
  → 자유 문장 추궁
  → 보수 협상
  → 의뢰서 작성
  → 접수 또는 거절
  → 지원 파티 검토와 인계 승인
  → 결과 대조
  → 의뢰인 2·3
  → 결산
```

## Do Not Build

- 길드 건물과 확장
- 길드 홀 탐색
- 모험가 육성·장비 구매
- 소문·세력·관계
- 저장·장기 캠페인
- 음성·TTS
- 모바일·게임패드
- 태도·화법 선택 버튼
