# Story 007 — 창구 화면 검증 기록

**Date**: 2026-08-08 · **Story Type**: UI (ADVISORY 게이트)
**Build**: `vite dev` @ localhost:5173 · **Viewport**: 1280×720

## 증거의 종류

스토리는 "스크린샷 + 수동 확인"을 요구하지만, **자동 상호작용 테스트 18개**
(`tests/unit/presentation/counterScreen.test.ts`, happy-dom)로 대체·보강했다.

이유: 이 화면의 핵심 회귀 조건은 *"결렬된 의뢰의 진실이 DOM에 없다"* 인데, 이것은
**눈으로 확인할 수 없다.** 스크린샷에 안 보인다고 DOM에 없는 것이 아니다. 한번 깨지면
"알아내는 것"의 값이 0이 되므로 자동 테스트로 고정하는 편이 맞다.

> **스크린샷 미첨부.** 이 세션의 브라우저 창이 표시되지 않아 렌더 프레임을 캡처할 수
> 없었다. 대신 실제 브라우저에서 DOM 텍스트를 추출해 아래에 기록했다. 제출물 3번용
> 스크린샷은 Story 017(시각 폴리시)에서 일괄 촬영한다.

## 실제 브라우저 확인 결과

### 초기 렌더

```
니카 발더
위험도 57 · 기본 보상 170G · 소요 1일 · 정원 1명
보상  170G (×1.00)
선불  0G (0%)
위험 고지  이 의뢰의 실제 위험을 아직 모른다.
[제안한다]  남은 기회 2회
```

콘솔 오류 0건.

### Manual: 비활성 사유 표시 — **PASS**

위험 고지 토글이 `disabled`이고 사유가 붉은 봉랍색으로 표시된다:
*"이 의뢰의 실제 위험을 아직 모른다."*

한 문장으로 읽히고, **무엇을 하면 열리는지 유추 가능하다** — 실제 위험을 알아내면
된다는 것. 회색 버튼만 있었으면 버그로 읽혔을 자리다.

### Manual: 응답 속도 — **PASS**

`performance.now()`로 클릭 → 화면 반영 측정: **1.7ms** (예산 100ms).

슬라이더 조작은 전체 재렌더를 하지 않고 숫자 표시만 갱신하므로 드래그 중에도 슬라이더가
손에서 빠져나가지 않는다. 확인: 슬라이더를 ×2.50으로 옮긴 뒤 DOM 노드 동일성 유지,
표시값 `426G (×2.50)`으로 갱신됨.

### Manual: 결렬 시 진실 은폐 — **PASS** (자동 고정됨)

`test_broken_negotiation_never_reveals_the_truth`가 2회 거부 후 `root.innerHTML`에
실제 위험도(137)와 문자열 `realRisk`가 없음을 단언한다. 렌더 자체를 하지 않으므로
DOM을 뒤져도 값이 없다.

### Manual: capability 미노출 — **PASS**

이 화면은 모험가를 그리지 않으므로 역량 숫자가 새어 나갈 경로 자체가 없다.
`test_capability_numbers_do_not_appear`가 명부 22명의 역량값이 DOM에 없음을 확인한다.

### 흥정 왕복 — **PASS**

의뢰인 두 명에게 각각 다른 축으로 과한 조건을 제시했다:

| 의뢰인 | 제시 | 반박 |
|---|---|---|
| 미라 벨트 | 보상 ×3.00 | "미라 벨트**가** 고개를 저었다. “보수를 그렇게 부르시면 곤란합니다.”" |
| 세리 슈타인 | 선불 100% | "세리 슈타인**이** 쏘아붙였다. “못 믿겠다는 말씀이십니까.”" |

지목된 축이 각각 보상·선불로 정확히 갈렸다. 남은 기회 표시도 2회 → 1회로 감소.

## 이 세션에서 잡은 버그

**한국어 조사가 받침을 따르지 않았다.** 최초 렌더에서 *"니카 발더**이** 눈살을
찌푸렸다"* 가 나왔다 — `발더`는 받침이 없으므로 `가`여야 한다. 템플릿이 `{client}이`로
고정돼 있던 탓이다.

브라우저로 직접 보지 않았으면 못 잡았을 종류다. 단위 테스트는 전부 통과하고 있었다.

**조치**: `render()`에 `{name|이/가}` 형태를 추가해 받침으로 조사를 고르게 했다.
숫자도 한자음 읽기를 따른다(87 → 팔십칠 → `은`). `names.json` 168개 조합 전체에 대해
조사가 붙는지 테스트로 고정했다.
