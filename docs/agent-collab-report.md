### C. 문서/Skill 분리 체크리스트 (점진 확장)

#### 1) 문서 분리
- [ ] PR/기여 절차가 복잡해졌다면 `CONTRIBUTING.md` 분리
- [ ] 완료 기준이 길어졌다면 `docs/done-criteria.md` 분리
- [ ] 요구사항 변화가 잦다면 `docs/requirements.md` 분리
- [ ] 페이지/라우팅 복잡도가 올라가면 `docs/pages-map.md` 분리

#### 2) Skill 분리
- [ ] 반복 구현 작업이 많다면 `.codex/skills/page-implementation/SKILL.md` 생성
- [ ] 버그 수정 패턴이 반복되면 `bugfix-workflow` Skill 추가
- [ ] 문서 누락이 반복되면 `docs-sync` Skill 추가
