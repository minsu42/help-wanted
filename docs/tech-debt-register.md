# 기술 부채 레지스터

> 기준: 2026-08-10 신규 접수 수직 단면 구현 완료 후

## 해결됨

- 구 길드 경영 도메인과 진입점 제거
- 선택 행동 기반 심문 제거
- 선택지 생성 프록시를 `/interpret`·`/respond` AI 계약으로 교체
- 전체 재렌더 기반 구 화면 제거
- 구 의뢰서·파견 공식과 테스트 제거
- 미사용 런타임 에셋 제거

## 잔여 항목

### TD-001 — 실 AI 모델 품질 평가

- **상태:** Open
- **문제:** 로컬 개발용 에이전트와 Worker 계약은 검증했지만 실제 배포 모델의 한국어 해석 정확도와 지연을 아직 계측하지 않았다.
- **해소 조건:** 대표 발화 세트에서 슬롯·자료 지식·금액 해석 정확도 90% 이상, p95 응답 8초 이내.

### TD-002 — 의뢰인별 고유 초상

- **상태:** Open
- **문제:** 세 의뢰인이 같은 4프레임 표정 아틀라스를 공유한다.
- **해소 조건:** 신원 일관성을 유지하는 고유 초상 3세트 제작과 1280×720 검수.

### TD-003 — 서버 권위 영수증

- **상태:** Accepted for qualifier
- **문제:** `ToolReceipt` 멱등성은 클라이언트 규칙 엔진이 보장하며 서버 서명은 없다.
- **결정:** 싱글플레이 예선에서는 치팅 방지보다 환각 격리가 중요하므로 유지한다. 외부 순위나 공유 기록을 도입할 때 서버 권위로 이전한다.

### TD-004 — 실제 브라우저 장시간 AI 완주

- **상태:** Open
- **문제:** 개발 에이전트로 3사건 완주는 확인했지만 프로덕션 Worker로 15분 연속 세션을 아직 검증하지 않았다.
- **해소 조건:** 배포 Worker로 세 사건 완주 5회, 상태 오염·미공개 사실 누출·중복 턴 0회.
