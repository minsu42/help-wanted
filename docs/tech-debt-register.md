## Deferred — 의식적으로 미룬 확장

- **2026-08-08 — LLM 서술 레이어 (story-019 이후 검토).** 대사를 런타임에 LLM으로
  생성하는 안을 검토했고 **결과 대조 화면(story-014) 한 지점에만, 배포 스모크 이후에**
  얹기로 했다.

  기술적 장애물은 없다 — 프록시(Cloudflare Worker)를 세우면 API 키 노출은 해결되고,
  서술 텍스트는 판정에 들어가지 않으므로 결정론도 깨지 않는다 (`(seed, eventId)`
  캐싱으로 재생도 안정적).

  **미루는 이유는 일정이다.** 남은 스토리 14개 추정 합이 20.5h인데 실질 가용은
  14~16h로 이미 초과 상태이고, LLM 레이어는 프록시 2~4h + 프롬프트 안정화 3~6h +
  캐시·폴백 1~2h로 6~12h를 더한다. 게다가 폴백이 필요하므로 **템플릿 엔진(story-006)은
  어차피 만들어야 한다** — 대체가 아니라 추가다.

  결과 대조를 고른 이유: 호출량이 파견당 1회로 적고, 결과를 보는 순간은 1~2초 대기가
  오히려 무게를 싣고, 감정적 페이로드가 거기 있으며(*"당신은 사흘 전에도 그를
  보냈다"*), **왜곡 숫자가 없다.** 왜곡은 소문 쪽에 있고 결과 대조는 진실을 밝히는
  화면이라 LLM이 건드릴 수치가 없다.

  창구 흥정과 홀 대화는 제외한다 — 매 상호작용마다 호출이라 100ms 응답 예산과
  충돌하고, 소문에는 성격별 왜곡값이 실려 있어 LLM이 그 숫자를 뭉개면 *"저 친구 말은
  늘 과장이니 깎아 듣자"* 라는 학습 신호가 죽는다.
