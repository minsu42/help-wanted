# 에셋 출처와 런타임 사용 상태

## 현재 런타임 에셋

| 파일 | 역할 | 출처 |
|---|---|---|
| `client-portrait-expressions.png` | 의뢰인 감정 4프레임 | OpenAI 생성 후 프로젝트 정규화 |

생성 프롬프트와 정규화 이력은 다음 문서가 소유한다.

- `design/art/source/client-portrait-expression-v1.md`
- `design/art/source/counter-desk-objects-v1.md`
- `design/art/asset-manifest.json`

## 참고 라이선스

초기 시각 방향은 Pixel-boy와 AAA의 `Ninja Adventure Asset Pack`을 참고했다. 해당 팩은 CC0 1.0 Universal이며 출처는 `https://pixel-boy.itch.io/ninja-adventure-asset-pack`이다. 현재 런타임에는 해당 팩에서 직접 추출한 파일이 남아 있지 않다.

## 반입 규칙

- 공개 저장소와 Pages 배포에 재배포 가능한 라이선스만 사용한다.
- 새 에셋은 원본, 라이선스, 생성·변형 과정과 런타임 사용 여부를 기록한다.
- 빌드에서 참조되지 않는 런타임 에셋은 제출 전 제거한다.
