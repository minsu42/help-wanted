# Art Bible — Help Wanted

> **상태:** 새 접수 심사 콘셉트 정본
>
> **화면 기준:** 1280×720 데스크톱 웹

## Visual Thesis

**창 너머의 사람과 책상 위의 종이가 한 화면에서 기싸움한다.**

게임은 2D 픽셀 창구 디오라마다. 상단에는 AI 의뢰인의 얼굴과 몸짓, 하단에는 플레이어가 실제로 다루는 자료집·증빙·의뢰서·도장이 있다. 현대식 대시보드보다 중세 관청의 비좁은 책상처럼 보여야 한다.

## Composition

```text
┌──────── 자료집·증빙 ────────┬───── 의뢰인 창구 ─────┐
│ 책, 규정 쪽지, 제출 문서       │ 정면 상반신과 표정      │
├──────── 작성 중 의뢰서 ──────┼───── 대화 기록 ───────┤
│ 후보 사실, 등급, 준비, 도장     │ 대화 기록과 자유 입력창 │
└─────────────────────────────┴───────────────────────┘
```

- 의뢰서가 가장 밝고 큰 오브젝트다.
- 의뢰인은 화면 면적의 약 30%를 차지해 표정을 읽을 수 있어야 한다.
- 자료집과 증빙은 화면을 떠나는 별도 메뉴가 아니라 책상 위에서 겹쳐 열린다.
- 자유 입력창은 종이 메모 띠처럼 보이되 텍스트 가독성과 캐럿은 현대 웹 수준으로 선명해야 한다.

## Palette

| 역할 | 색상 | 용도 |
|---|---|---|
| 짙은 목재 | `#2b2118` | 책상·창틀·배경 |
| 양피지 | `#e8dcc0` | 의뢰서·자료집 본문 |
| 바랜 종이 | `#d6c8a6` | 증빙·부차 정보 |
| 먹색 | `#211b16` | 본문·선 |
| 봉랍색 | `#8f2f2f` | 도장·사망·중대한 규정 위반만 |
| 청동 | `#8b6b3f` | 금속 테두리·중립 강조 |

새 강조색을 시스템별로 추가하지 않는다. 상태는 색보다 모양과 문구로 구분한다.

## Character Direction

의뢰인은 정면 64×64 네이티브 픽셀 초상을 3배 또는 4배 정수 확대한다.

필수 상태:

| 상태 | 얼굴·몸짓 |
|---|---|
| 평정 | 시선 정면, 안정된 입, 양손 고정 |
| 동요 | 시선 흔들림, 입술 압박, 손이 서류로 이동 |
| 경계 | 고개 뒤로, 눈썹 하강, 팔이 몸 쪽으로 닫힘 |
| 분노 | 상체 전진, 눈썹·입 각도 강함, 손이 책상을 침 |

표정은 정답 표시가 아니다. 무지와 은폐가 같은 동요를 보일 수 있어야 한다.

## Paper Language

- 사실 후보: 출처 꼬리가 달린 작은 종이 쪽지.
- 확정: 또렷한 먹과 닫힌 원 아이콘.
- 추정: 옅은 먹과 반원 아이콘.
- 미상: 빈 칸과 점선.
- 자료 인용: 관련 문장을 들은 의뢰인이 자료집을 잠시 바라봄.
- 도장: 물리적으로 눌리고 잉크가 번진 뒤 의뢰서가 잠김.

## Motion

- 책 펼침: 160~220ms.
- 자료집 열람: 책갈피와 페이지가 140~180ms로 전환됨.
- AI 대기: 2초 안에 시선·손·호흡 중 하나가 시작됨.
- 표정 변화: 즉시 교체보다 100~160ms의 짧은 포즈 전환.
- 도장: 내려찍기 90ms, 충격 정지 50ms, 복귀 140ms.

화면 흔들림은 도장과 사망 보고서 첫 노출에만 매우 약하게 사용한다.

## Typography

- 한글 본문은 DOM 텍스트로 렌더링한다.
- 본문 최소 15px, 대화 17px, 핵심 수치 18px.
- 픽셀 폰트가 한글 가독성을 해치면 제목과 라벨에만 사용한다.
- 줄 길이는 대화 34자, 자료집 42자를 권장한다.

## Sound Direction

핵심 소리는 다섯 개다.

1. 타자 또는 펜 긁힘
2. 종이 넘김
3. 자료집 페이지 넘기기
4. 도장 충격과 잉크 소리
5. 결과 보고서 펼침

AI 대기 중 음악을 키우지 않는다. 침묵과 작은 몸짓 소리가 기싸움을 만든다.

## Accessibility

- 상태는 색만으로 전달하지 않는다.
- 의뢰인의 표정 변화는 대화 기록에 짧은 서술로도 남긴다.
- 모든 종이 조작은 키보드 포커스를 지원한다.
- 입력창, 자료집, 의뢰서는 200% 브라우저 확대에서도 핵심 기능이 가려지지 않아야 한다.

## Bestiary Plate

백과사전 괴물 페이지는 한 장의 2×2 픽셀 도판을 CSS로 분할한다. 미믹, 늪불 도깨비, 트롤, 마력석 화물이 같은 양피지·먹선·광원 체계를 공유한다. 이미지에는 기능 텍스트를 굽지 않으며 크기·서식·흔적·특성·약점·위험은 DOM으로 표시한다.

## Reusable Assets

현재 PNG 초상·표정·책상 오브젝트는 새 화면에 맞는 경우 재사용한다. 길드 홀·배정·결산 와이어프레임 PNG는 구현 근거가 아니며 새 화면 검증에 사용하지 않는다.

에셋 출처와 생성 이력은 `design/art/source/*.md`, `design/art/asset-manifest.json`이 소유한다.
