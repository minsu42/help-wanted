## 0. 전제 — 대화 입력의 원자는 4개뿐이다

세상의 모든 대화 게임 입력은 이 넷의 변주다:

| 원자 | 동작 | 대표 |
|---|---|---|
| **고르기** | 주어진 후보 중 선택 | 발더스 게이트, 매스 이펙트 |
| **조합하기** | 부품을 모아 문장/수를 만듦 | Golden Idol, Griftlands |
| **짚기** | 화면의 무언가를 가리킴 | 역전재판, Papers Please |
| **서술하기** | 자유 언어로 씀/말함 | Façade, Suck Up! |

나머지는 전부 **(a) 무엇을 짚거나 고르는가, (b) 어떤 물리 동작으로
꺼내는가, (c) 상대 반응을 어떻게 연출하는가**의 변주다.

### 판정 기호

- ✅ 채택(v6 확정) · ◎ 유력 · △ 조건부/보류 · ⚠ 기각 이력 있으나 재평가 여지 · ❌ 부적합

## 7. 종합 — 책상 레이아웃이 입력을 절반 결정한다

레이아웃(상단 창구+의뢰인 / 하단 책상: 의뢰서+길드마스터북 / 측면 UI)에서
책상 위 물건이 곧 동사가 된다:

```
        ┌─────────────────────────────┐
        │   의뢰인 (초상 + 기색)        │  ← 반응이 나오는 곳
        │        [창구]               │
        ├──────────────┬──────────────┤
 수첩/  │   의뢰서      │  길드마스터북  │   응대권
 들은것 │  (칸=질문)    │  (지식=열쇠)   │   기록
        └──────────────┴──────────────┘
```

- **묻기** = 의뢰서 칸 짚기 (C1, 공짜)
- **일깨우기** = 책/수첩 항목을 **창구 너머로 밀어 준다** (C5)
- **들이대기** = 같은 항목을 상대 말 기록에 **맞대어 잇는다** (C4)
  — 같은 자원, 정반대 방향이라는 GDD의 핵심 대칭이 **드래그 방향의 대칭**이 됨
- **압박의 잔돈** = 도장에 손 얹기 (E3), 기다리기 (E1)
- **기둥 6의 입력단** = 받아쓰기 반응 (D6)
- **LLM의 자리** = 전 구간 대사 생성(연출) + 선택적 D4

## 8. 결론 — 재미의 축은 입력이 아니라 반응이다: "의뢰인이 내 책상을 본다"

v3~v5의 미해결 문제 "대화 같지 않다"의 진짜 원인 추정: **입력 채널을 아무리
바꿔도, 상대가 내 행동을 보지 않으면 대화가 아니다.** 대화감은 입력 방식이
아니라 **피드백 밀도**에서 온다.

**핵심 제안: 플레이어가 책상에서 하는 모든 행동이 의뢰인에게 관찰되고,
반응을 낳는다.**

| 내 행동 | 의뢰인의 반응 예 |
|---|---|
| 칸에 값을 적는다 (D6) | 힐끔 본다 — *"…그렇게 크진 않았습니다만."* |
| 도감을 뒤적인다 | *"…책에는 뭐라고 나옵니까?"* (불안/기대) |
| 도장에 손을 얹는다 (E3) | 자세가 굳는다. 한 마디를 더 흘린다 |
| 아무것도 안 한다 (E1) | 침묵을 못 이기고 스스로 채운다 |
| 틀린 것을 들이댄다 | 불쾌해한다 — 관계 비용이 눈에 보인다 |

### 불변 가드레일

**의뢰인은 내가 "한 것"에만 반응한다. "안 한 것"(빈칸)에는 절대 반응하지
않는다.** *"규모는 안 적으십니까?"* 같은 대사는 금지 — 그것은 창구가 정답을
알려주는 것이고, GDD의 "창구는 끝까지 침묵한다"와 기둥 6을 동시에 무너뜨린다.

### 프로토 5의 검증 질문

> 입력은 v6 그대로(클릭/드래그)인데, **받아쓰기 반응 + 책상 관찰 반응**만
> 얹으면 "대화하고 있다"는 감각이 생기는가?

우선순위: ① D6 받아쓰기 반응 → ② C4/C5 드래그 방향 대칭 → ③ E1 침묵 →
④ E3 도장 압박. D4(자유 타이핑)는 이번 프로토에서 제외 — 변수를 하나로 유지.

## 9. 채택안 (2026-08-10 확정) — "서류가 대화의 조종간인 맥락형 대화"

**입력 방식 탐색을 여기서 닫는다.** 5개 조합안 비교와 외부 의견 검토를 거쳐 확정.
GDD 반영: `design/gdd/intake-system.md` **v6.1**.

### 채택 조합

**C1**(칸 짚기) + **C4/C5**(들이대기/건네기의 방향 대칭) + **D6**(단정 적기 = 붉은
잉크, 판정 불변) + **E1/E3**(침묵·도장 압박 — 연출층 양념) + **F1/F3**(턴제 +
의뢰인의 인내). 기각 확정: **A4**(생성 선택지), **D2/D4**(자유 타이핑 — 향후
「특이사항 한 줄」처럼 판정 불변 지점만 검토), **B4**(카드), **C2**(앵커).

### 확정 흐름

```
평소 책을 자유롭게 열람·기억                ← 준비 자산. 접되 잠그지 않는다
            ↓
의뢰인이 순순히 말할 사실을 무료로 진술      ← 깊이는 노브 (전부 기본 / 1단만 / 최소)
            ↓
남은 칸을 무료로 질문해 장애물 진단          ← 묻기·캐묻기 전부 무료
       ┌────┴────┐
     정말 모름     알고도 숨김
       ↓              ↓
 지식을 건넨다      근거를 들이댄다           ← 성공 무료, 헛발만 인내 소모
       └────┬────┘                          ← 인내 바닥 = 사람이 떠난다
            ↓
     기록·단정·빈칸 중 결정                  ← 검은 잉크(사실) / 붉은 잉크(단정)
            ↓
         도장 — 대가는 파견 결과에서 회수
```

### 핵심 문장 셋

1. **책은 항상 존재하는 준비 자산이고, 대화에서 벽을 발견한 순간 그 지식의 사용처가
   생긴다.** 막힘 시 자동 열림·탭 강조 금지 — "후보 중 고르기"가 아니라
   *"아까 읽은 것이 이 상황에 걸린다"*.
2. **결정은 "어디를 물을까"가 아니라 "확인된 장애물 중 어디에 내 지식을 걸까"에
   모인다.** 그래서 진단은 무료이고 헛발만 비싸다.
3. **반응 계층(8절)은 연출이지 동사가 아니다.** 의뢰인은 내가 한 것에만 반응하고,
   빈칸은 절대 언급하지 않는다.

### UI 감량 지침 (다음 프로토 = 현재 안의 감량판)

완료 점수(`2.5/3`) 삭제 · 대화는 최근 1~2교환만 크게(과거는 접기) · 책은 평소
접힘(책등/탭) · 시스템 설명 축소 · 반응 계층은 양념 취급.
