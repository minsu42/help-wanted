# 창구 심사 UX 정본

> 기준 화면: 1280×720 데스크톱 / 마우스·키보드
> 상태: Approved for implementation — 2026-08-10

## 고정 레이아웃

루트는 `100dvh`이며 body 스크롤을 금지한다. 헤더 아래 왼쪽은 책상 도구, 중앙은 의뢰인과 최근 대화·입력, 오른쪽은 진술 쪽지와 확인 기록이다. 모든 긴 목록은 자체 스크롤을 갖는다.

## 핵심 상호작용

| 행동 | 입력 | 즉시 피드백 | 결과 |
|---|---|---|---|
| 질문 | 자유 문장 | 의뢰인 생각 중 | 허용된 사실과 반응 |
| 진술 선택 | 쪽지 클릭 | 봉랍색 테두리 | 대조의 왼쪽 항목 고정 |
| 근거 선택 | 책 문장 클릭 | 선택 문장 강조 | 대조의 오른쪽 항목 고정 |
| 대조 | 대조 도장 | 유효/무관 안내 | 유효 시 추궁 모드 |
| 추궁 | 자유 문장 | 두 근거 스트립 유지 | 은폐 사실·감정 변화 |
| 게시 | 의뢰서 도장 | 서류 잠김 | 지원서 계산 |
| 인계 | 지원서 승인 | 승인 도장 | 파견 결과 |

## 오버레이

백과사전은 양면 책, 장부는 세로 기록지다. 둘 다 `role=dialog`, 닫기 버튼, 배경 차단을 제공한다. 책은 두 페이지 단위로 넘기며 각 괴물 페이지는 도판과 크기·서식·흔적·특성·약점·위험을 포함한다. 동적 텍스트와 선택 버튼은 이미지에 굽지 않는다.

## 접근성

- 모든 조작은 네이티브 button/input/select로 구현한다.
- 선택, 완료, 위험은 색뿐 아니라 테두리·문구로 구분한다.
- 포커스 링은 금색 3px이다.
- 모션 감소 설정에서 모든 장식 애니메이션을 사실상 제거한다.
- 모바일은 제출 대상이 아니지만 320px 이상에서 기능을 잃지 않도록 3열 축약과 내부 스크롤을 유지한다.

## 수용 기준

- 대화 20턴에서도 body 스크롤 높이가 viewport를 넘지 않는다.
- 최근 대화를 보면서 입력창과 진술 쪽지가 항상 같은 화면에 남는다.
- 책을 열고 문장을 선택한 뒤 닫아도 선택이 보존된다.
- 유효하지 않은 대조는 AI 호출이나 인내 소모 없이 거부된다.
- 파티 지원서는 의뢰서 도장 이후에만 나타난다.
