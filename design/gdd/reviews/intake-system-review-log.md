### Summary

척추는 튼튼하다 — 소유권 경계가 깨끗하고, 결정론이 타입 수준에서 강제되며(`Rng` 미import),
`미상`/`막힘` 분리가 기둥 6에 정확히 물려 있다. 차단 항목은 전부 국소적이고 값싸며 구조
변경을 요구하지 않는다. 가장 중대한 발견은 **문안 질감의 스키마 부재**였다 — Player
Fantasy가 핵심이라 선언하고 이 저장소의 과거 사고(`rumorNothingToTell`)까지 인용한
`무지`/`은폐` 구별이, 정작 그것을 실어 나를 수단(#6)을 Dependencies에서 **Soft**로 표시하고
있었다. 판정은 돌지만 게임이 죽는 유형이다. 가장 날카로운 단일 발견은 **평평한 ±2%p
몬테카를로 허용 오차**로, 갱단의 4.7% 버킷에서 9.5σ에 해당해 망가진 구현도 통과시켰다.

### 전문가 간 이견 (봉합하지 않고 남긴다)

- **클릭 앵커가 판타지를 훼손하는가.** game-designer는 앵커가 *어느 단어가 중요한지*
  미리 알려주는 소프트 드롭다운이라 봤고, creative-director는 앵커가 **질문을 고르는
  것이 아니라 받아 적는 것**이므로 과장이라 반박했다. → **타협 반영**: 시스템은 그대로
  두고, *"앵커 하나가 후보 하나와 1:1 대응되면 안 된다"* 를 **U2①의 데이터 작성 규약**으로
  넣었다. 1:1이 되는 순간 game-designer의 지적이 실제로 성립하기 때문이다.
- **은폐형 P4 유보가 절벽인가.** game-designer는 절벽, creative-director는 관리가 P1에
  남아 저강도 연습이 되므로 경사라고 봤다. → 미해결 R3.
- **청취록의 책상 자리 비용.** ux-designer가 스스로 축소 — 대사띠가 최신 답변을 공짜로
  보여주므로 마찰은 과거 답변 교차 참조 때만 발생.
- **R7의 키스트로크마다 필터링 성능.** ui-programmer가 스스로 비이슈로 결론.

## 2차 개정 — 2026-08-09 — 리뷰 후속 (판정 없음)

리뷰가 미해결로 남긴 **어휘 빈곤 문제**를 해결하며 규칙을 개정했다. 새 리뷰는 아니고
1차 리뷰의 후속 작업이다. 근거 문서:
`design/research/interrogation-games-market-2026-08-09.md` (시장조사).

### 무엇이 문제였나

리뷰의 game-designer가 *"카탈로그가 슬롯 단위 공용이라 몇 시간 안에 전부 학습된다"* 를
지적했고(1차 미해결 목록의 배경), 개정 중에 **더 강한 형태로 확인됐다**:

**R4(*"질문 하나가 상한까지 간다"*) + R10(문안 소유가 슬롯에 있다)를 같이 놓으면 같은
슬롯을 겨냥한 질문 둘은 완전히 같은 수가 된다** — 도달점도 같고 출력 문안도 같으므로
키워드 차이만 남는다. 즉 **슬롯당 질문은 사실상 1개**이고 카탈로그는 6개다.

그러면 Player Fantasy의 *"떠올리지 못한 여덟 개"* 와 *"이 시스템이 이 게임의 진짜 진행
시스템"* 이 8~15시간 캠페인에서 **거짓이 된다.**

### 해결 — 질문 깊이 등급 (선택지 (나))

| 변경 | 어디 |
| ---- | ---- |
| `reach = min(knows, tells, **depth**)` — 뭉툭(`vague`)/날카(`certain`) 2등급 | F1 · R4 |
| **뭉툭하게 열어야 날카롭게 파고들 수 있다** — 없으면 날카가 완전 지배 | **R4-2** 신설 |
| `limiter` 3값화 — **`질문`** 신설 (*"의뢰인이 아니라 내가 벽이었다"*) | F2 |
| "재질문"을 `depth ≤ 현재 상태`로 재정의 | R6 |
| 슬롯 어휘 **6개**, P1 의뢰 종류 **4종**, 카탈로그 **12개** | 「슬롯 어휘와 의뢰 종류」 신설 |
| 검산표 2체제 + **행동 칸 1개당 수익률** 표 | F4 |
| 문안 키 슬롯당 5종 → **6종**, 전체 36종 | R10 |
| **하루 행동 칸 = 의뢰인 × 슬롯 = 12** | Tuning Knobs |
| AC 13개 신설·개정 | AC 절 A·B |

### 시장조사가 결정을 뒤집은 지점 하나

검토 초기에 *"(나)가 안티 기둥 「정답이 있는 적발 퍼즐」에 (가)보다 가깝다"* 고 판단했다.
**L.A. Noire 사례가 그 반대를 보여줬다** — 정답 퍼즐이 되는 것은 선택지가 **하나의 옳은
값으로 붕괴할 때**이고, 비평가들의 처방이 *"틀린 선택에도 부분 정보가 나왔어야 한다"*
였다. 뭉툭한 질문이 `모호`를 주는 것이 그 처방이다. **(나)의 실제 리스크는 정답화가
아니라 "두 번 누르는 절차화"이며, 방어는 Q4 하나뿐이다.**

그리고 Ace Attorney의 `Press`(무비용 단일 등급 → *"전부 눌러라"* 가 공식 공략)가
**(가)의 미래를 그대로 보여준다.** 그 게임이 무너지지 않은 이유는 `Present`에 5회
페널티가 있어서다. **그래서 Q4는 (나)의 부속물이 아니라 전제 조건으로 격상됐다.**

### 우연히 맞아떨어진 것 — 기록해 둘 값어치가 있다

F4 수익률 표를 계산해 보니 **튜닝하지 않았는데** 기존 `w[slot]` 상한(3:1)과 깊이/넓이
비율(~3×)이 상쇄되어, **상인·관리는 깊이가 옳고, 귀족·갱단은 넓이가 옳고, 주민은 정확히
동점**이 된다. 직업을 읽고 전략을 바꾸는 것이 실제로 옳은 플레이가 된다(기둥 1).

⚠ **그러므로 `w[slot]` 3:1과 `depth` 2단계는 한 몸이다.** 어느 한쪽만 튜닝하면 균형이
깨진다 — Tuning Knobs 간섭 항목에 넣었다.

### 해소된 Open Question / 신설된 것

- **Q1 해소** — 카탈로그는 의뢰 종류가 아니라 슬롯 어휘에만 비례하고 어휘는 6개에서
  멈춘다. **Q1의 전제(선형 증가)가 틀렸다.**
- **Q4 잠정 확정** — 공식 `의뢰인 × 슬롯`. GATE 실측만 남았다
- **Q8 신설** — `limiter='질문'`이 억울함이 되지 않는가. **이번 개정의 가장 큰 수확이면서
  유일하게 검증되지 않은 감정**이고, 실패하면 기둥 6의 실패 모드에 걸린다.
  화면이 아무 표시도 하지 않기로 정했으므로(F2 완화안) **문안의 질감만으로** 전달돼야 한다

### 미해결로 남은 시장 리스크 — 설계 밖 ⬜

**배포 채널이 정해져 있지 않다.** 8~15시간 캠페인 + GitHub Pages 웹 배포는 itch에는
너무 길고, Steam에 올리려면 웹 전제(서버 없음 등)가 만든 기술 결정 상당수가 의미를 잃는다.
**로드맵에 이 결정이 없다.** (가)/(나)와 독립이지만 더 크다 — P8 이전에 답이 필요하다.
