# 진술 대조형 AI 심문

> 상태: Designed — NAN 2026 예선 P0
> 상위 문서: `design/gdd/game-concept.md`

## 목적

AI 자유 대화의 표현력은 유지하면서, 핵심 진술 검증은 플레이어가 직접 조작하고 규칙이 확정한다. 대조는 거짓 적발뿐 아니라 정직한 진술의 확인에도 사용한다.

## 턴 구조

1. 의뢰인은 사건·관찰·추측·보수를 포함한 3~5문장 최초 진술을 한다.
2. 중요 발언은 `openingClaims`에 따라 3~4개 진술 쪽지로 표시된다.
3. 진술 쪽지와 `KnowledgeEntry` 문장을 하나씩 선택한다.
4. `compareClaim`이 사건의 지식 요구 조건을 검증한다.
5. 유효하면 근거 모드가 열리고 선택한 두 기록이 입력창 위에 고정된다.
6. 책 문장을 자동 삽입하지 않으며 플레이어가 읽고 자유 문장으로 추궁하거나 확인한다.
7. 선택 ID를 AI 해석 결과에 강제로 병합한 뒤 `resolveTurn`이 공개 가능한 사실만 연다.

대조가 ‘무엇을 묻는가’를 고정하고 자연어가 ‘어떻게 묻는가’를 표현한다. 협박·공감·화법 선택 UI는 만들지 않는다.

## 실패와 피드백

- 무관한 두 기록: 인내를 소모하지 않고 “직접 대조할 수 없다”를 표시한다.
- 근거 없는 공격: 기존대로 인내 감소와 경계 상승이 가능하다.
- AI 호출 실패: 입력 문장과 선택한 대조를 보존하고 재시도한다.
- 같은 턴 ID: 기존 영수증을 반환해 중복 공개하지 않는다.

## UI 요구사항

- 중앙에는 최근 네 턴만 표시하고 내부 스크롤한다.
- 전체 대화는 대화 장부에서 과거 순서대로 확인한다.
- 진술 쪽지는 선택·대조 완료 상태를 문구와 모양으로 함께 표시한다.
- 유효한 대조 후 입력 라벨을 `이 대조를 근거로 무엇을 확인하시겠습니까?`로 바꾼다.
- 백과사전이 열려도 선택한 진술 상태는 유지한다.

## 완료 조건

- 지식 선택 없이 은폐 사실이 열리지 않는다.
- 유효한 물리 대조는 AI가 지식 ID를 놓쳐도 규칙 판정에 반영된다.
- 존재하지 않는 지식 ID는 무시된다.
- 자유 입력 외 태도 버튼이 없다.
