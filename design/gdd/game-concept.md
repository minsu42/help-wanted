## 한 문장 콘셉트

**말을 숨기거나 잘못 아는 AI 의뢰인의 진술을 중세 괴물 백과사전과 대조해 의뢰서를 게시하고, 그 서류만 믿고 지원한 모험가의 생사를 책임지는 판타지 길드 접수 게임.**

## 게임의 약속

플레이어는 길드마스터가 아니라 창구 접수원이다. 의뢰인은 첫 진술부터 사건·관찰·추측·보수를 3~5문장으로 말하며 중요 발언은 ‘진술 쪽지’가 된다. 플레이어는 실제 책처럼 펼쳐지는 백과사전에서 괴물의 크기·서식·흔적·특성·약점·위험과 길드 규정을 찾는다. 진술과 책 문장을 골라 대조 도장을 찍은 뒤, 자신의 문장으로 모순을 추궁하거나 정직한 진술을 확인한다.

확인한 내용은 의뢰서에 기록해 게시한다. 파티는 실제 진실이 아니라 기록된 위험·보수·준비만 보고 지원하며, 플레이어는 지원자 중 한 팀에 인계를 승인한다. 전투 결과는 질문, 대조, 서류의 정확성이 사람을 살렸는지 보여준다.

## 시장 포지션과 차별점

- `Papers, Please`: 문서에서 이상점을 찾아 두 기록을 물리적으로 대조하는 손맛
- `Strange Horticulture`: 책을 펼쳐 그림과 특징을 탐색하는 지식 놀이
- AI 심문 게임: 고정 선택지가 만들 수 없는 질문과 캐릭터 반응

차별점은 자유 대화를 별도 미니게임으로 두지 않고 `진술 선택 → 지식 선택 → 대조 → 자유 추궁 → 검증된 사실 → 의뢰서 → 지원 파티 → 결과`라는 닫힌 인과 사슬로 만든다는 점이다. 시장 근거와 출처는 `design/research/nan2026-market-2026-08-10.md`가 소유한다.

## 핵심 플레이 루프

```text
의뢰인 최초 진술
  → 자유 질문으로 세부 진술 확보
  → 진술 쪽지 선택
  → 길드 백과사전에서 문장 선택
  → 대조 도장
  → 대조 결과를 자유 문장으로 추궁·확인
  → 보수 협상
  → 의뢰서 작성·게시 도장
  → 도착한 파티 지원서 검토
  → 한 파티에 인계 승인
  → 실제 사건과 결과 대조
```

## 입력 원칙

대화 태도·협박·공감 버튼은 없다. 자유 입력은 질문, 추궁 표현, 협상에만 사용한다. 반면 무엇을 대조하는지는 플레이어가 쪽지와 책 문장을 직접 선택하므로 AI 해석 실패가 핵심 퍼즐 판정을 빼앗지 않는다.

- 일반 모드: 자유 질문과 협상
- 대조 모드: 진술 하나 + 자료 문장 하나를 선택하고 대조 도장
- 근거 모드: 선택한 진술과 책 문장이 입력창 위에 고정되고, 자유 문장으로 추궁·확인
- 규칙 엔진: 선택 ID가 실제 사건 규칙과 연결되는지 검증
- AI: 문장의 의도·말투를 이해하고 허용된 사실을 캐릭터로 연기

## 길드 백과사전

책상 위 `길드 백과사전` 버튼을 누르면 양면 책이 화면 위에 펼쳐진다. 두 장씩 넘기며 다음을 읽는다.

| 괴물 도감 | 길드 규정·시세 |
|---|---|
| 픽셀 도판 | 조항 문장 |
| 크기와 사람 대비 | 접수 금지 조건 |
| 서식지 | 등급별 최소 보수 |
| 남기는 흔적 | 위험수당 |
| 행동 특성 | 목표 우선순위 |
| 약점과 위험 등급 | 증빙 기준 |

책 상단에는 `전체·괴물·규정·위장종·정령종·거인종·마력·시세·구조` 태그가 있다. 책 문장마다 `이 문장을 증거 슬롯에 끼우기`가 있다. 선택한 문장은 입력창에 자동 복사되지 않는다. 플레이어가 내용을 읽고 자기 말로 질문해야 하며, 선택 ID는 규칙 판정 근거로만 사용된다.

## 화면과 대화 기록

게임 화면은 항상 `100dvh` 안에 고정된다. 새 대화가 생겨도 문서 전체가 아래로 길어지지 않는다.

```text
┌──── 책상 도구 ────┬──────── 의뢰인·최근 대화 ────────┬──── 진술·확인 기록 ────┐
│ 백과사전 버튼       │ 초상 / 최근 네 턴 / 자유 입력      │ 진술 쪽지 / 대조 도장   │
│ 전체 대화 장부       │ 추궁 시 선택한 두 근거 고정         │ 확인 사실 / 의뢰서 버튼 │
└───────────────────┴───────────────────────────────┴──────────────────────┘
```

최근 대화는 내부 영역에서만 스크롤한다. 전체 과거 대화는 `대화 장부` 오버레이에서 확인한다. 백과사전과 장부는 창구를 떠나는 별도 페이지가 아니라 책상 위에 겹쳐 열린다.

## 의뢰서와 파티 지원

의뢰서에는 목표, 대상, 규모, 장소·경로, 특징·약점, 위험 등급, 준비, 합의 보수를 기록한다. 사실은 확정·추정·미상 중 하나다. 게시 도장 후 내용은 잠기며, **지원자가 한 팀도 없을 때만** 다시 작성할 수 있다. 지원서가 도착한 뒤에는 고칠 수 없다 — 누가 지원하는지 보고 위험 등급을 고쳐 쓰는 것은 기둥을 무너뜨린다.

플레이어는 전체 모험가 명단을 관리하지 않는다. 게시된 의뢰를 읽고 0~3개 파티가 지원한다.

```text
지원 점수 = 보수 적합 + 기록 위험 적합 + 준비 역량 적합
```

위험을 낮게 쓰면 강한 파티가 외면하고 약한 파티가 지원할 수 있다. 위험을 과장하면 보수 부족으로 지원자가 사라질 수 있다. 플레이어는 도착한 지원서 중 하나에 `인계 승인`을 누른다.

## AI 활용

AI는 단순 문장 생성기가 아니라 각 의뢰인의 기억, 오해, 은폐 목적, 감정과 협상 태도를 지속해서 연기한다. 같은 대조 근거라도 플레이어가 어떻게 추궁했는지에 따라 반응과 관계가 달라진다. 다만 사건 진실, 공개 조건, 예산 상한, 유효한 대조, 지원과 생환 판정은 TypeScript 규칙 코어가 소유한다.

이 분업은 NAN 2026에서 AI 활용을 분명히 한다. 정해진 버튼만 누르는 퍼즐이 아니라 플레이어의 자연어가 캐릭터 상호작용을 만들고, 결정적 판정은 재현 가능한 규칙으로 검증된다.

## 의뢰인 콘텐츠

| 사건 | 거짓 구조 | 학습 목표 |
|---|---|---|
| 양조장 저장고 | 쥐로 오해한 미믹 | 흔적 대조와 약점 기록 |
| 봉인 없는 마차 | 밀수 마력석 은폐 | 규정 대조와 정당한 거절 |
| 늪의 불빛 | 의뢰인의 선의의 오해 | 괴물 식별과 구조 우선 |
| 돌다리 트롤 | 모든 관찰과 보수를 정직하게 제시 | 자료로 사실을 확인하고 적합 파티 모집 |
| 늪지 구조 | 전문가가 정답에 가까운 정보를 제공 | 접수원이 정보를 정확히 문서화하는 책임 |
| 마력석 사고 | 과실과 합법 증빙을 먼저 공개 | 밀수와 합법 사고를 구분하고 보수 교정 |

모든 의뢰인이 비밀을 숨기지 않는다. 6명은 `기만 1·오해 2·정직/자진신고 3`으로 구성한다. 정직한 의뢰인은 대조를 거짓 적발이 아니라 신뢰도 높은 사실 확정에 사용한다.

## 범위

포함: AI 의뢰인 6명, 자유 질문·추궁·협상, 복수 진술 쪽지, 태그형 실물 백과사전, 대조 도장, 의뢰서 게시, 지원 파티 승인, 결과 대조.
제외: 장기 경영, 모험가 육성, 장비 구매, 전체 로스터 편성, 길드 밖 이동, 음성, 모바일·게임패드.

## 완료 기준

- 화면 전체는 대화 턴 수와 무관하게 고정되고 모든 긴 내용은 내부 스크롤 또는 오버레이를 쓴다.
- 진술과 유효한 백과사전 문장을 선택한 뒤에만 대조 추궁 모드가 열린다.
- 별도의 협박·공감·태도 버튼이 없다.
- AI가 발명한 사실은 의뢰서·판정에 반영되지 않는다.
- 게시 후 지원 파티가 기록된 위험·보수·준비로 계산된다.
- 파티는 지원서에서만 승인하며 게시 전 직접 배정하지 않는다.
- 결과 보고서가 최초 주장, 실제 사건, 정보·준비·위협의 인과를 보여준다.
- 시연용 첫 3사건을 15분 안에 완주할 수 있고 전체 콘텐츠는 6사건이며 `npm run check`가 통과한다.
