# Game Concept: Help Wanted

**Status:** Ship scope locked
**Updated:** 2026-08-10 — 8주 캠페인 및 길드 홀 게시판 흐름 확정

## 한 줄 설명

몰락한 길드의 신임 길드마스터가 불완전한 진술을 질문으로 파고들고, 보수를 합의하고,
위험도를 판정해 모험가를 보내며 그 결과를 책임지는 선택 중심 경영 게임.

## 플레이어 경험

- 의뢰서의 칸을 직접 짚어 질문하고, 내 대사와 의뢰인의 반응을 대화로 확인한다.
- 의뢰인의 표정과 답변으로 무지와 은폐를 구분한다.
- 의뢰인이 먼저 낸 보수에 수락·시세 요구·위험 수당 요구로 응답하고, 필요하면 역제시를 받는다.
- 길드 홀 게시판에서 여러 의뢰를 비교해 파견하며, 일부 의뢰를 다음 주로 미룰 수 있다.
- 성공·부상·사망과 그 원인을 결과 화면에서 이해하고 다음 판단에 반영한다.

## 출시판 핵심 루프

캠페인은 **8주**다. 한 주의 순서는 다음과 같으며 주 진행은 길드 홀에서 단 한 번만 일어난다.

1. 그 주의 새 의뢰인 **3명**이 정해진 순서로 온다.
2. 각 의뢰인에게 `질문 선택 → 내 대사 → 표정 → 답 → 후속 선택` 순서로 청취한다.
3. `의뢰인의 선제 제안 → 수락/시세 요구/위험 수당 요구 → 필요 시 역제시`로 보수를 합의한다.
4. 플레이어가 위험도 `D/C/B/A/S`를 골라 의뢰서에 날인한다.
5. 세 의뢰가 끝나면 길드 홀로 이동한다.
6. 게시판에서 날인된 의뢰를 골라 파견 인원을 배정한다. 길드 등급의 동시 파견 한도까지 복수 파견할 수 있다.
7. **이번 주를 마감한다**를 누르면 파견 결과·경제·신뢰·회복을 한 번 처리하고 다음 주로 간다.
8. 파견하지 않은 의뢰는 게시판에 남아 다음 주에도 배정할 수 있다.

8주차를 마감하고 도착한 결과를 모두 본 뒤 결산으로 이동한다.

## 출시 범위

- 시드 기반 세계·의뢰·결과 생성
- 의뢰인 직업, 초상, 표정 4종
- 의뢰서 7칸 질문, 무지/은폐, 인내, 길드마스터북, 일깨우기/들이대기
- 선택형 보수 합의와 의뢰인 지불 여력 기반 수락·역제시
- 위험도 날인, 길드 홀 게시판, 미배정 의뢰 이월
- 파티 편성, 동시 파견 한도, 파견 판정, 부상·사망
- 결과 대조, 길드 홀 대화·소문·영입, 자금·명성·확장
- 8주 진행, 결산, 재시작
- 마우스와 키보드로 완주 가능한 반응형 UI

## 제출 후로 미루는 것

- LLM 연기와 프록시 배포
- 저장/불러오기
- 세력 평판, 가치관·관계 확장, 세계 변화, 3막 서사
- 추가 의뢰 템플릿·캐릭터·아트·오디오

## 밸런스 원칙

진행 불가, 즉시 파산, 항상 같은 선택처럼 플레이를 막는 값부터 고친다. 모든 수치는
`src/data/balance.json`에서 조정하며 코드에 새 매직 넘버를 만들지 않는다.

## 출시 완료 기준

- `npm run check` 통과
- 실제 브라우저에서 접수 3명 → 보수 합의 → 날인 → 길드 홀 복수 파견 → 주 마감 → 결과 → 다음 주가 연결됨
- 미배정 의뢰가 다음 주 게시판에 유지됨
- 8주차 마감 뒤 새 의뢰를 만들지 않고 결과를 모두 보여준 다음 결산함
- 막힌 버튼, 가려진 핵심 조작, 설명 없는 진행 불가 상태가 없음
