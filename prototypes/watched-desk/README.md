## 가설

**입력 규칙은 v6(프로토 4) 그대로 두고, 반응 계층만 얹으면 "대화하고 있다"는
감각이 생기는가?**

v3~v5는 입력 방식(타이핑→앵커→선택지)을 바꿔도 "대화 같지 않다"가 안 풀렸다.
원인 추정: 대화감은 입력이 아니라 **피드백 밀도**에서 온다 — 상대가 내 행동을
보지 않으면 대화가 아니다. 이 프로토는 판정 규칙을 한 글자도 바꾸지 않고
**의뢰인이 플레이어의 책상을 관찰하게** 만든다.

## 얹은 것 다섯 (전수조사 문서의 우선순위 ①~④ + 관찰 반응)

| # | 반응 | 전수조사 | 무엇이 새로운가 |
|---|---|---|---|
| ① | **받아쓰기 반응** — 책 항목을 빈 칸에 「단정」으로 적으면(무료) 의뢰인이 힐끔 보고 한마디. 반응의 결은 그 칸에 대한 상대의 상태가 정한다: 모름→"저로서는…", 은폐→기색이 굳는다, 동떨어짐→"…그게 상관이?" | D6 | **쓰는 행위가 대화의 수가 됐다.** 단정 칸은 붉은 잉크로 남고, 도장 요약에 "네가 적었고 아무도 확인해 주지 않았다"로 나온다 — 기둥 6의 입력단 |
| ② | **방향 대칭** — 항목을 집어(클릭) 창구에 놓으면 「건넨다」(일깨우기), 막힌 칸에 놓으면 「들이댄다」 | C4/C5 | 프로토 4의 모달 목록이 사라지고, GDD의 "같은 자원을 정반대 방향으로"가 **놓는 자리의 대칭**이 됐다. 일깨우기는 칸 지정이 없다 — 건넨 이야기 스스로 어느 무지 칸에 닿는지 찾는다 |
| ③ | **침묵** — 「기다린다」를 누르면 침묵을 못 이기고 **아픈 곳의 결**(손익/절차/체면)을 흘린다. 직업별 인내 횟수(주민 2, 갱단 0). 갱단은 침묵을 받아넘긴다 — 그것도 정보다 | E1 | 들이대기 범주 선택에 근거가 생겼다. 사건의 새 사실은 흘리지 않는다 (경제 불침범) |
| ④ | **도장 압박** — 도장 버튼이 2단이 됐다: 손을 얹는다(기색이 굳고 한마디) → 그대로 찍는다 | E3 | 확인 대화상자가 연출이 됐다 |
| ⑤ | **책 훔쳐보기** — 책 탭을 처음 넘기면 "…책에는 뭐라고 나옵니까?" | 관찰 | 조사하는 모습 자체가 관찰된다 |

## 가드레일 (불변)

**의뢰인은 내가 "한 것"에만 반응한다. "안 한 것"(빈칸)에는 절대 반응하지 않는다.**
"규모는 안 적으십니까?"는 금지 — 창구가 정답을 알려주는 것이고 기둥 6이 무너진다.
react() 프롬프트에 명시 + 도장 반응은 빈칸 언급 금지 조항이 따로 있다.

## 규칙 중 프로토 4와 달라진 것 (판정은 동일)

- 일깨우기/들이대기 재료 선택이 **모달 → 집어서 놓기**가 됐다
- 일깨우기는 칸을 지정하지 않는다 (건넨 내용이 맞는 무지 칸을 스스로 찾는다)
- 「단정 적기」 신설 — 무료, 판정에 영향 없음, 서류에만 남는다 (본선 반영은 P2 대조의 몫)
- 「칸당 상한」(Q3) 노브는 뺐다 — 이 프로토의 질문이 아니다
- 명시적 「비워 두고 넘어간다」 행동 제거 — 채우지 않는 것 자체가 스킵이다

## LLM 소관 — 생성 둘, 분류 없음 (ADR-003 준수)

## 재는 것

1. **"대화하고 있다"는 감각이 생겼는가** — 이 프로토의 존재 이유. 규칙은 그대로다
2. **단정 적기가 무섭게 느껴지는가** — 무료인데도 손이 무거운가 (기둥 6)
3. **은폐 칸에 단정을 적었을 때 기색 변화를 알아채는가** — 판별의 새 채널
4. **집어서 놓기가 모달보다 나은가** — 건네기/들이대기의 방향이 몸에 남는가
5. **침묵·도장·책 반응이 과한가 모자란가** — 반응 밀도의 적정선

## 3회차 (2026-08-10) — 1회차 플레이 판정 다섯 반영

판정: ***"말해놓고 갑자기 모른다" · "로그가 오른쪽이라 안 보임" · "대화 중간에
갑자기 다른 내용" · "책이 너무 대놓고 정보" · "존댓말/반말 오락가락" ·
"응대권 빼고 끝까지 대화하는 게 낫나?"***

| # | 문제 | 조치 |
|---|---|---|
| ① | 말해놓고 갑자기 모른다 | **칸별 기왕력**을 LLM에 주고 부정 금지("아는 건 거기까지" 태도) + **역방향 필터** — told 판정인데 밝혀진 사실의 낱말이 대사에 없으면 그 대사를 버리고 폴백 교체 (누출 필터의 쌍둥이. 정답 보기에 「배신차단」 카운트) |
| ② | 로그가 안 보임 | **대화 리본**을 창구 바로 아래 무대 중앙으로. 측면은 시스템 기록만 |
| ③ | 갑자기 다른 내용 | **반응 대기열** — 턴 진행 중 반응은 대기열에 넣고 한가할 때만 발화. 반응 말풍선은 혼잣말 모양(점선·이탤릭)으로 구별 |
| ④ | 책이 너무 대놓고 | `data.js` — 18항목을 **개념·통념·소문** 층위로 재작성한 프로토 전용 사본. id·태그 동일 = 판정 불변, 본선 `quest-templates.json` 불변. 책과 정답 사이 추론 거리가 "아!"의 크기다 |
| ⑤ | 말투 오락가락 | **말투 계약** — 직업별 어미를 예문과 함께 고정(주민 더듬는 존댓말 / 관리 문어체 / 귀족 하오체 / 갱단 반말) + "절대 섞지 마라". turn()·react() 공통 |
| ⑥ | 응대권 빼? | **빼지 않고 옮겼다** — 추상 토큰 → **의뢰인의 인내**(창에 ● 표시). 수학 동일(시도마다 1). 벽 도달(묻기)은 원래 공짜였고, 뚫기 무제한이면 책 18개 전수 들이대기가 정답 전략이 되어 판별이 죽는다. 실패로 바닥나면 **자리를 뜬다** — 한계가 게임 밖 규칙이 아니라 눈앞의 사람이다 |
