## 두 프로토

같은 마르타, 같은 진실(외눈 오우거), 같은 행동 칸 8개. 뼈대만 다르다.

| | A — 슬롯 × 깊이 | B — 신뢰 게이지 | C — 단서 그물 |
|---|---|---|---|
| 질문의 축 | **무엇을** 묻는가 (슬롯) | **어떻게** 말하는가 (화법) | **대사에 나온 것**을 파고든다 |
| LLM 분류 | 질문 → (slot, depth) | 발화 → (tone, topic) | 발화 → (열린 노드 id, tone) |
| 진행 규칙 | reach = min(knows, tells, depth) | 화법 → 게이지 → 임계값 공개 | 부모 노드를 들어야 자식이 열림 (그물 깊이 3~4) |
| 은폐(아들 비밀) | 도달 불가 — 막힘(은폐) 감지만 | 게이지 8 이상 | **기색(머뭇거림)** 발견 → 그 순간에만 화법 판정 (공감이 연다) |
| 슬롯의 지위 | 화면에 보이는 **메뉴** (체크리스트화 — 1차 플레이테스트에서 실패 판정) | 없음 (조각 목록) | 청취 중 숨김 — 알아낸 것의 **보상** |
| 잡담/불성립 비용 | 무비용 | 칸 소모 | 무비용 (그물 밖 질문은 칸 안 씀) |

> **C가 나온 경위 (2026-08-10 1차 플레이테스트):** A는 "슬롯 4개를 각각 물으면 끝 —
> 클릭과 다를 바 없다", B는 "화법을 고를 동기가 없다"는 판정을 받았다. 공통 뿌리는
> **물을 수 있는 것이 메뉴로 보였다**는 것. C는 물을 거리를 대사 안에만 두고(단서 연쇄),
> 화법 판정을 기색이 발견된 순간으로 국소화한 재설계다.

마지막에 둘 다 **의뢰서 작성**(안 2 미리보기)으로 끝난다 — 위험도·인원을 정하고
특이사항을 **자유 서술**하면 파티장 브란(LLM)이 의뢰서만 읽고 준비 목록을 짠다.
그 뒤 세계의 진실이 공개되어 "내가 쓴 만큼만 그들이 준비했다"를 대조할 수 있다.

## 2차 개정 (2026-08-10) — 보수 흥정 추가, 권장 인원 제거

1차 플레이테스트 피드백 "애매하다 + 보수가 왜 없나"에 대한 응답. 진단: **청취를
진공에서 테스트하고 있었다** — 정보에 값이 없으면 파고들 이유도 없다.

- **보수 흥정**: 청취 종료 후 의뢰비를 제시한다. 마르타의 지갑(35은 상한, 25은까지 무난,
  초과 시 30은 역제안)은 **규칙이 소유**하고 마르타는 결과를 연기만 한다 — 말로 우겨도
  없는 돈은 안 나온다 (Where Winds Meet 방지). 26~35은은 "겨울 땔감 값을 헌다" —
  받을 수 있지만 죄책감이 남는 구간.
- **권장 인원 제거**: 인원은 브란이 의뢰서(위험도·정보·보수)를 읽고 스스로 정한다.
  보수가 위험 대비 짜면 인원을 줄이거나 불평한다 — 네가 쓴 것과 매긴 값이 파티 규모를
  결정한다 (기둥 6 강화).

## 3차 확장 (2026-08-10) — 하루 3의뢰인 판 (`day.html`)

"몸통 없이 기관만 테스트했다"는 진단의 검증. 단서 그물(C) × 처리량 압박(공유 행동 칸 12개).

- **의뢰인 3인, 여는 열쇠가 전부 다르다**: 마르타(주민 — 공감이 연다) / 델마르(상인 —
  위험을 축소하고 값을 후려침, 논리·압박이 연다) / 로스(수상한 자 — **어떤 화법도 안
  통한다**, 받을지 말지가 진짜 결정)
- 의뢰별로 돌려보내기 가능. 하루 마감에 파티장 3인이 각 의뢰서를 읽고 준비를 짜고,
  진실 대조 + 수입 합산이 나온다.
- **검증 런 결과 (2026-08-10)**: 빈 의뢰서 + 15은 → 브란이 **1명**만 파견 (진실: 오우거
  — 전멸각). 충실한 의뢰서 + 40은 → 셀린이 **4명** + 경계 강화 (진실: 도적 5인 — 거의
  대비). **같은 날 안에서, 캐낸 만큼의 차이가 인원 1명 vs 4명으로 보였다.**

## 4차 확장 (2026-08-10) — 길드마스터북 + 아침 국면 (지원-선택 배정)

- **길드마스터북** (우측 패널, 정적 데이터): 짐승 도감 / 의뢰 시세표 / 지역 기록부 /
  조직·인물 소문첩. **후보를 줄 뿐 답은 주지 않는다** (GDD 길드마스터북 원칙).
  시세표가 로스의 100은을 소급으로 수상하게 만들고, 도감 대조가 "발자국 두 뼘 + 단독 +
  야행 + 생나무"를 오우거 후보로 좁혀준다.
- **아침 국면 (3안 — 지원-선택 하이브리드)**: 하루 마감 → 다음 날 아침, 파티 3개
  (브란의 도끼 3인·중 / 셀린의 은시위 4인·상 / 요른의 떠돌이들 2인·하)가 게시판의
  의뢰서를 읽고 **지원 / 조건부 / 무시**를 정한다. 플레이어가 지원자 중 배정 (파티당
  1건). 출발 → 파견 판정(파티 역량 + 의뢰서 vs 진실) → **완수한 의뢰만 정산.**
- **검증 런 (2026-08-10)**: 정보 0짜리 D급 25은 의뢰서 → 브란 "정보가 너무 부족하다"
  무시, 셀린 "시간 낭비" 무시, **요른만 지원** → 배정 → **부상 철수 · 보수 정산 0** —
  "의뢰서에 적힌 정보의 부족으로 도적단의 존재를 전혀 알지 못했다."
  **의뢰서의 질 → 지원자의 질 → 파견 결과 → 수입**의 4단 인과가 한 판에서 보였다.
- 페르소나 붕괴 수정: 연기 프롬프트에 "인물 밖으로 나오지 마라" 명시 (1차 유저
  플레이테스트에서 로스가 "적합하지 않습니다" 등 어시스턴트 말투를 냈다).
- 파견 판정은 프로토 한정으로 LLM 판정관을 쓴다 — **본 구현에서는 규칙 판정으로 교체
  대상** (진실·역량·의뢰서 반영도를 수치화). 조사 문서의 교훈 2(판정자를 LLM으로 삼지
  마라)와 충돌하는 것을 알고 쓰는 임시 장치다.

## 5차 개정 (2026-08-10) — 2차 유저 플레이테스트("너무 빡세다") 반영 4건

1. **파견 판정을 규칙으로 이관** — LLM 판정관이 "오우거 예상" 특이사항을 무시하고
   셀린 4인을 도적 5인에게 전멸시키는 과잉 가혹 판정을 냈다 (조사 교훈 2의 재현).
   교체: LLM은 **대비 추출만**(의뢰서가 진실 항목을 덮음/부분/비어있음 — 좁은 채널),
   결과는 **전력(역량×2+인원) + 대비(0~4) − 위협** 수식이 정하고, LLM은 서술만 한다.
   수식은 화면에 그대로 노출. 검증: "오우거 예상" 의뢰서 → 대비 4 → 요른도
   `4+4−6=2` 진통 끝 완수.
2. **대화 이력 전달 (티키타카)** — 연기 호출이 매번 첫 대화였던 것이 단발감의 원인.
   의뢰인별 이력(최근 12줄)을 넘긴다. "직접 본 건 아니라고 하셨는데"에 자연스럽게 이어짐.
3. **표면 진술 선개방** — start 직결 노드는 의뢰인이 앉자마자 무료로 다 말한다.
   행동 칸(12→9)은 진술 속 수상한 지점을 파고드는 데만 쓴다 — "뭘 물어야 하지"가
   "어디가 수상하지"로 바뀐다.
4. **보수는 의뢰인이 먼저 부른다** — 마르타 18은(가난) / 델마르 30은(후려침) /
   로스 100은(시세 4배 — 그 자체가 경보). 수락 또는 역제시.

부수 발견: 정보를 완벽히 캐도 보수가 싸면(마르타 18은) 상급 파티가 안 붙는다 —
가난한 의뢰인의 위험한 의뢰라는 **구조적 딜레마**가 창발했다 (셀린: "오우거를 상대할
보수가 시세 이하라니, 웃기군"). 기둥 긴장의 재료.

## 판별 질문 (플레이 후 답할 것)

   **"이 사람을 어떻게 열지?"**(B의 재미)였나?
2. 은폐(아들 비밀)를 만났을 때: A의 "막힘 — 여기엔 뭔가 있다"가 흥미로웠나,
   B의 "공감으로 풀어서 들었다"가 흥미로웠나?
3. 행동 칸 8개의 긴장감은 어느 쪽에서 더 살았나?
4. 30분 더 하고 싶은 쪽은? — **이 답이 P1 GDD 개정의 축이 된다.**
5. (안 2 검증) 특이사항을 자유 서술할 때, 토큰 부착보다 재미있었나?
   브란의 준비 목록이 내 문장을 정직하게 반영했나?
6. 혼합(슬롯 × 게이지 2축)이 필요해 보였나, 아니면 한쪽으로 충분한가?
